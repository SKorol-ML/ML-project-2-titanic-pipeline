## Описание проекта



На основе данных Titanic (Kaggle) разработан \*\*автоматизированный пайплайн\*\*, который:

- Загружает и разделяет данные.

- Выполняет предобработку (заполнение пропусков, кодирование категорий, масштабирование, создание новых признаков).

- Обучает три модели классификации (`LogisticRegression`, `RandomForestClassifier`, `XGBClassifier`) с кросс-валидацией и подбором гиперпараметров.

- Выбирает лучшую модель и сохраняет её вместе с препроцессором.

- Оценивает качество модели и визуализирует результаты (матрица ошибок, ROC-кривая).



Весь код вынесен в модули `src/`, что делает его переиспользуемым и готовым к интеграции в реальные проекты.

## Пайплайн предобработки



Пайплайн (`create\_preprocessor` в `preprocess.py`) выполняет следующие шаги:



1. \*\*Добавление новых признаков\*\*:  

- `FamilySize = SibSp + Parch + 1`  

- `IsAlone = (FamilySize == 1)`

2. \*\*Числовые признаки\*\* (`Age`, `Fare`, `FamilySize`, `IsAlone`):  

- Заполнение пропусков медианой.  

- Стандартизация (`StandardScaler`).

3. \*\*Категориальные признаки\*\* (`Sex`, `Embarked`, `Pclass`):  

- Заполнение пропусков константой `'missing'`.  

- One‑Hot кодирование (`handle\_unknown='ignore'`).



Все трансформации применяются к обучающей выборке через `.fit\_transform()`, а к тестовой — только `.transform()`, что предотвращает утечку данных.

## Обучение моделей



В модуле `train.py` реализована функция `train\_and\_select\_model`, которая:

- Принимает подготовленные данные (`X\_train`, `y\_train`, `X\_test`, `y\_test`).

- Для каждой из трёх моделей запускает `GridSearchCV` с 5‑кратной кросс‑валидацией по ROC‑AUC.

- Возвращает лучшую модель (по ROC‑AUC на тесте) и словарь с результатами.



\*\*Сетки параметров (сокращённые для скорости):\*\*



| Модель | Параметры |

| :--- | :--- |

| LogisticRegression | `C`: \[0.1, 1.0, 10.0] |

| RandomForest | `n\_estimators`: \[50, 100], `max\_depth`: \[3, 5, None], `min\_samples\_split`: \[2, 5] |

| XGBoost | `n\_estimators`: \[50, 100], `max\_depth`: \[3, 5], `learning\_rate`: \[0.01, 0.1], `subsample`: \[0.8, 1.0] |

## Результаты



### Сравнение основных моделей



После выполнения `05\_final\_pipeline.ipynb` были получены следующие результаты на тестовой выборке (20% данных):



| Модель | CV ROC‑AUC | Test ROC‑AUC | Лучшие параметры |

| :--- | :--- | :--- | :--- |

| \*\*LogisticRegression\*\* | \*\*0.847\*\* | \*\*0.848\*\* | `{'C': 1.0, 'l1\_ratio': 0}` |

| RandomForest | 0.842 | 0.842 | `{'max\_depth': 5, 'min\_samples\_split': 5, 'n\_estimators': 100}` |

| XGBoost | 0.838 | 0.834 | `{'learning\_rate': 0.1, 'max\_depth': 3, 'n\_estimators': 100, 'subsample': 0.8}` |



\*\*Лучшая модель — логистическая регрессия\*\* с ROC‑AUC \*\*0.848\*\*. Это показывает, что на структурированных данных небольшого объёма простая линейная модель не уступает сложным ансамблям, а даже превосходит их благодаря меньшей склонности к переобучению.



### Упрощенная модель (эксперимент)



Для проверки влияния количества признаков обучена модель (ноутбук `06\_test\_simple\_model.ipynb`) только на \*\*4 признаках\*\*: `Age`, `Pclass`, `Sex` и `IsAlone`. Предобработка выполнялась без `ColumnTransformer`, вручную.



\*\*Результаты на том же тестовом сплите:\*\*



- Accuracy: \*\*0.7821\*\*

- ROC‑AUC: \*\*0.8355\*\*

\## Установка и запуск



1. Клонируйте репозиторий:

git clone https://github.com/ваш-username/ml-project-2-titanic-pipeline.git  
cd ml-project-2-titanic-pipeline



2. Установите зависимости:

pip install -r requirements.txt
